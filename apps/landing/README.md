# Website and control plane (`apps/landing`)

The Next.js 16 app behind **skillissue.vodka**, hosted on Vercel. It does two jobs:

1. **The homepage** explains the game: the poster, roles, how to join, the guns and the map.
2. **A small API** the game and phones need to find each other, plus the AI match MVP.

A permanent snapshot of the page, with full-page screenshots, is in [docs/website](../../docs/website/README.md).

## Run it

From the repository root:

```sh
pnpm landing:dev      # local dev server
pnpm landing:build    # production build
pnpm landing:lint
```

## How the homepage is served

`/` shows `public/home-preview.html`, a self-contained poster-style page, through a rewrite in `next.config.ts`. The original React homepage in `src/app/page.tsx` (with `leaderboard.tsx`) is kept, untouched. To go back to it, delete the `rewrites()` block.

## API routes (`src/app/api/`)

The game and phones call these, so changes to the homepage should leave this folder alone.

| Route | Called by | Does |
| --- | --- | --- |
| `POST /api/games` | Godot game | Provisions a lobby and returns its unique `/games/<gameId>` WebSocket URL on the relay |
| `GET /api/connection` | Phone app | Tells phones which relay to connect to |
| `POST /api/mvp` | Godot game, at the final whistle | Asks Gemini to pick the match MVP from the stats |
| `POST /api/mvp/badge` | Godot game | Asks Gemini to draw the MVP's raccoon badge |
| `GET /api/leaderboard` | Original homepage | Reads the top scores from Tiger Data; returns 503 when it isn't configured |

## Environment variables (set in Vercel)

| Variable | Used by | Notes |
| --- | --- | --- |
| `NEXT_PUBLIC_GAME_SERVER` or `GAME_SERVER_URL` | `/api/games`, `/api/connection` | The relay's `wss://` URL |
| `GEMINI_API_KEY` | `/api/mvp`, `/api/mvp/badge` | Without it, the game picks the MVP with its own rule and labels the card "Judged offline" |
| `GEMINI_MODEL` | `/api/mvp` | Default `gemini-flash-latest` |
| `GEMINI_IMAGE_MODEL` | `/api/mvp/badge` | Default `gemini-3.1-flash-image` |
| `TIGER_DATABASE_URL` or `DATABASE_URL` | `/api/leaderboard` | See [the leaderboard doc](../../docs/leaderboard-database.md) |

The relay itself (long-lived WebSocket traffic) does not run on Vercel. See [`apps/server`](../server/README.md) and [online play setup](../../docs/online-play-setup.md).
